# 高光时刻识别指南

分析游戏录像时读取。本文档提供各类型游戏的高光识别标准、时间轴标注方法和精彩度评分。

---

## 高光识别总原则

高光 = 观众看到会"哇""哈哈""牛"的瞬间。判断标准：
1. **情绪波动**：玩家语音激动/爆笑/惊呼
2. **视觉冲击**：特效密集、数字跳动、画面变化大
3. **结果意外**：反杀、翻车、稀有掉落
4. **技术含量**：操作难度高、连招流畅
5. **信息密度**：短时间内发生多件事

## 高光时间轴标注方法

### 标注格式
```
{
  "start": "00:32.5",      // 开始时间（精确到0.5秒）
  "end": "00:45.0",        // 结束时间
  "type": "击杀",          // 高光类型
  "score": 5,              // 精彩度 1-5
  "desc": "1v3反杀",       // 简短描述
  "emotion": "激动",       // 玩家情绪
  "slowmo": true,          // 是否需要慢放回放
  "caption": "这波1v3"     // 花字内容
}
```

### 标注流程
1. 用 byted-mediakit-video 抽帧/分析，标记候选高光
2. 人工/AI 复核每个候选，确认是否为高光
3. 评分 1-5，低于 3 分的不入选
4. 按时间排序，生成最终时间轴
5. 检查节奏：避免连续 3 个同类型高光

### 精彩度评分标准
- **5分**：教科书级、罕见、会被反复观看
- **4分**：很精彩、有技术含量或节目效果
- **3分**：还不错、可入选但不是重点
- **2分**：普通、可快进跳过
- **1分**：无聊、必须剪掉

## 剔除标准（必须剪掉）

| 内容 | 处理方式 |
|---|---|
| 加载画面 | 全删 |
| 排队/匹配 | 全删或 3x 快进 |
| 选人/准备 | 3x 快进，只留关键选择 |
| 跑路超过 5 秒无事件 | 2x 快进或剪掉 |
| 重复刷怪/采集 | 只保留第一次，其余剪掉 |
| 沉默超过 10 秒 | 剪掉或快进 |
| 语音聊天无关内容 | 剪掉（除非搞笑） |
| 卡顿/掉帧 | 剪掉 |

## 开头钩子选择

开头 3-5 秒必须放全片最精彩的瞬间，选择标准：
1. 优先 5 分高光
2. 视觉冲击力强（特效/数字/动作）
3. 有悬念（"他能反杀吗？"）
4. 有节目效果（搞笑/翻车）
5. 不要剧透最终结果（留悬念）

钩子后加 1-2 秒过渡："这把开局是这样的..."然后回到正片开始。
