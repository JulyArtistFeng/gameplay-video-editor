# 游戏视频风格预设库

规划剪辑风格时读取。本文档提供各UP主风格参数、BGM库、花字弹幕库和转场预设。

---

## 风格预设

### 预设一：云顶猫咪风格（自走棋/轻松搞笑）
- **节奏**：中等偏快，高光密集，搞笑片段多
- **字幕**：大量趣味花字，内心 OS 多，弹幕风格
- **BGM**：轻快电子乐、魔性BGM、搞笑音效
- **片头**：可爱风格，猫咪元素，快闪高光
- **片尾**："求点赞关注"+ 下期预告
- **适合**：自走棋、休闲游戏、搞笑集锦
- **参数**：
  - 高光片段：正常速度
  - 跑路：2x 快进
  - 转场：闪白 + 缩放
  - 花字密度：高（每 10 秒至少 1 个）
  - BGM 音量：-18dB

### 预设二：燃向集锦风格（FPS/MOBA高光）
- **节奏**：快，卡点剪辑，高潮迭起
- **字幕**：简洁，击杀数字放大，少量花字
- **BGM**：电子乐/摇滚/史诗，鼓点卡点
- **片头**：游戏 logo + 快闪击杀画面 + 重低音
- **片尾**："关注看更多精彩操作"
- **适合**：FPS、MOBA、动作游戏高光集锦
- **参数**：
  - 高光：正常 + 0.3x 慢放回放
  - 转场：硬切 + 闪白
  - 击杀定格：1 秒
  - BGM 音量：-15dB，卡点切换
  - 音效：击杀音、冲击音

### 预设三：实况解说风格（完整对局/长视频）
- **节奏**：自然，保留玩家语音和反应，高光标注
- **字幕**：语音字幕为主，少量花字
- **BGM**：低音量轻音乐，不抢语音
- **片头**：本期主题 + 精彩预告
- **片尾**："点赞关注"+ 下期预告
- **适合**：完整对局、生存建造、剧情游戏
- **参数**：
  - 高光：正常速度，加"高光"标注
  - 无聊部分：1.5x 快进
  - 转场：淡入淡出
  - BGM 音量：-20dB
  - 玩家语音：保留完整

### 预设四：搞笑翻车风格
- **节奏**：快，翻车/搞笑片段密集
- **字幕**：大量花字、弹幕、内心 OS
- **BGM**：滑稽音乐、鬼畜、反转音效
- **片头**：最搞笑瞬间 + "今天你笑了吗"
- **片尾**："笑了就点个赞吧"
- **适合**：搞笑集锦、翻车合集、BUG合集
- **参数**：
  - 翻车瞬间：0.5x 慢放 + 滑稽音效
  - 转场：快切 + 卡通转场
  - 花字密度：极高
  - BGM：随内容突变（燃→滑稽）

## BGM 推荐库

### 燃向
| 曲名/风格 | 用途 | BPM |
|---|---|---|
| 史诗管弦（Epic Orchestral） | 翻盘、高潮 | 120-140 |
| 电子摇滚（Electronic Rock） | 击杀集锦 | 128-140 |
| Trap | 操作展示 | 140-160 |
| Drum & Bass | 快节奏FPS | 170-180 |

### 轻松/搞笑
| 曲名/风格 | 用途 | BPM |
|---|---|---|
| Lo-fi Hip Hop | 实况、日常 | 70-90 |
| 卡通/滑稽（Cartoon） | 搞笑、翻车 | 100-120 |
|  Ukulele | 休闲游戏 | 90-110 |
| 8-bit 芯片音乐 | 复古游戏 | 120-160 |

### 氛围/悬疑
| 曲名/风格 | 用途 | BPM |
|---|---|---|
| 环境音（Ambient） | 恐怖、探索 | 60-80 |
| 悬疑弦乐 | 紧张时刻 | 80-100 |
| 钢琴独奏 | 煽情、结尾 | 60-80 |

### BGM 获取
- 用 text_to_audio_plus 生成自定义 BGM
  - prompt："140BPM电子摇滚，燃向，游戏集锦配乐，无人声"
- 注意版权：使用免版权音乐或生成原创音乐

## 转场预设

| 转场 | 时长 | 适用场景 |
|---|---|---|
| 硬切 | 0秒 | 默认、快节奏、击杀之间 |
| 闪白 | 0.2秒 | 高光之间、击杀瞬间 |
| 缩放 | 0.3秒 | 进入高光、强调 |
| 淡入淡出 | 0.5秒 | 场景转换、节奏放缓 |
| 模糊 | 0.3秒 | 回忆、慢放前 |
| 滑入 | 0.3秒 | 搞笑、轻松内容 |
| 故障（Glitch） | 0.2秒 | 反转、意外、BUG |

## 片头片尾模板

### 片头模板（3-5秒）
```
0-1秒：游戏logo + UP主名称（快闪）
1-3秒：3-5个高光画面快速切换（0.5秒/个）
3-5秒：本期标题 + BGM Drop
```

### 片尾模板（5-8秒）
```
0-2秒：最后一个高光回放（慢放）
2-5秒："求点赞加关注，下期更精彩"（文字动画）
5-8秒：下期预告（1-2个镜头）+ 关注按钮
```

## 各平台适配

| 平台 | 比例 | 时长 | 特点 |
|---|---|---|---|
| B站 | 16:9 | 5-30分钟 | 完整内容、弹幕文化 |
| 抖音/快手 | 9:16 | 1-3分钟 | 快节奏、开头抓人 |
| 视频号 | 9:16 或 16:9 | 1-5分钟 | 社交传播 |
| YouTube | 16:9 | 10-30分钟 | 完整内容、SEO标题 |
| 小红书 | 3:4 或 9:16 | 1-5分钟 | 图文+视频、标签 |

竖屏适配：横屏素材裁剪中间区域，关键动作保持在画面中心。
