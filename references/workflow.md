# 游戏录制视频剪辑 · 详细工作流

开始执行游戏录像剪辑任务时完整读取。

---

## 第一步：分析录像，提取高光

### 素材读取
- 本地视频：直接使用
- 支持格式：MP4、MOV、AVI、MKV

### 高光分析（byted-mediakit-video）
分析视频，识别以下高光类型：

| 高光类型 | 识别特征 | 精彩度 |
|---|---|---|
| 击杀/淘汰 | 击杀提示、敌方血条清空、庆祝动作 | ★★★★★ |
| 精彩操作 | 连招、闪避、反杀、极限操作 | ★★★★★ |
| 翻盘 | 劣势→优势的转折点 | ★★★★★ |
| 搞笑瞬间 | 角色死亡姿势、意外事件、BUG | ★★★★ |
| 翻车/失误 | 自信操作→突然死亡 | ★★★★ |
| 稀有事件 | 稀有掉落、特殊触发、彩蛋 | ★★★★ |
| 普通战斗 | 常规击杀/对战 | ★★ |
| 跑路/采集 | 无冲突的移动/收集 | ★（剪掉） |
| 加载/等待 | 加载画面、排队、挂机 | ★（剪掉） |

### 输出高光时间轴
```
[
  {start: "00:32", end: "00:45", type: "击杀", score: 5, desc: "1v3反杀"},
  {start: "01:15", end: "01:22", type: "搞笑", score: 4, desc: "踩空掉崖"},
  ...
]
```

### 剔除标准
- 无聊跑路：超过 5 秒无事件的移动
- 重复操作：重复的刷怪/采集
- 加载画面：全部剪掉
- 沉默空白：无语音无操作超过 10 秒
- 准备阶段：选人/买装备等可快进

## 第二步：规划视频结构

### 时长选择
| 类型 | 时长 | 高光数量 |
|---|---|---|
| 短视频（抖音/快手） | 1-3 分钟 | 3-5 个高光 |
| 中视频（B站） | 5-10 分钟 | 8-15 个高光 |
| 长视频（完整局） | 15-30 分钟 | 完整对局+高光标注 |

### 结构模板
```
【开头钩子 3-5秒】全片最精彩瞬间（倒叙）
【过渡 2-3秒】"这把开局..."
【正文 70-80%】高光片段按时间线排列
  - 高光1（正常速度）
  - 高光1回放（慢放/多角度）
  - 过渡（快进）
  - 高光2
  ...
【结尾 10-15%】最燃/最搞笑收尾 + 引导关注
```

### 节奏曲线
- 开头：最高潮（钩子）
- 前 1/3：中等高光，建立节奏
- 中间：连续高光，密度最高
- 后 1/3：最燃/最搞笑，留到最后
- 避免：连续 3 个同类型高光（击杀+击杀+击杀会腻，穿插搞笑/翻车）

## 第三步：剪辑素材

### 基础剪辑（byted-mediakit-editing）
1. 按高光时间轴裁剪片段
2. 普通片段 1.5-2 倍速快进
3. 高光片段正常速度
4. 高光回放：0.3-0.5 倍慢放
5. 转场：快切为主，高光之间闪白/缩放

### 高级处理
| 效果 | 参数 | 用途 |
|---|---|---|
| 慢放 | 0.3-0.5x | 精彩操作回放 |
| 快进 | 1.5-3x | 跑路/准备阶段 |
| 定格 | 1-2秒 | 击杀瞬间/关键操作 |
| 缩放 | 1.5-2x | 突出关键区域（血量/装备） |
| 回放 | 正常→慢放 | 精彩操作再看一遍 |
| 闪白 | 0.2秒 | 高光之间转场 |
| 抖动 | 轻微 | 击杀/冲击瞬间 |

### 画面裁剪
- 横屏录制做竖屏视频：裁剪中间区域，保留关键动作
- 去除无关区域：聊天框、状态栏（除非是关键信息）

---

## 第四步：字幕与弹幕

### 字幕类型
1. **语音字幕**：玩家说话内容，底部显示，白色黑体
2. **趣味花字**：高光时刻添加"这波啊""绝了""寄了"
3. **内心 OS**：模拟玩家心理，黄色/粉色，上方显示
4. **弹幕风格**：关键操作飘过"？？？""666""就这？"
5. **数据标注**：伤害数字、金币、血量放大弹出

### 花字库
| 场景 | 花字 |
|---|---|
| 精彩操作 | "这波操作""666""秀""神了" |
| 击杀 | "拿下""带走""击杀""GG" |
| 翻车 | "寄了""下饭""啊这""离谱" |
| 搞笑 | "哈哈哈""绝了""什么鬼""笑死" |
| 翻盘 | "反转了""还有这种操作""牛" |
| 紧张 | "慌了""稳住""别啊""心跳加速" |

### 弹幕风格
- 从右向左飘过，速度中等
- 颜色：白色为主，关键弹幕用黄色/红色
- 密度：关键操作时 3-5 条，平时 0-1 条
- 内容：模拟真实观众反应

---

## 第五步：配乐与音效

### BGM 选择
| 视频类型 | BGM 风格 | 参考 |
|---|---|---|
| 燃向集锦 | 电子乐、摇滚、史诗 | 《Monody》《Rise》 |
| 搞笑剪辑 | 轻快、滑稽、魔性 | 鬼畜BGM、卡通音效 |
| 翻盘集锦 | 渐强激昂 | 《Victory》《Star Sky》 |
| 日常实况 | 轻松休闲 | Lo-fi、轻音乐 |
| 恐怖游戏 | 悬疑氛围 | 环境音、心跳 |

### 卡点剪辑
- BGM 鼓点/重音处切换画面
- Drop 处放最精彩的高光
- 安静段落放搞笑/翻车
- BGM 骤停配合翻车/意外

### 音效
- 击杀："BOOM""叮""唰"
- 搞笑："哇哦""失败""滑音"
- 震撼：冲击音、低音
- 转场："嗖""咔"
- 玩家语音保留为主音轨

### 音量
- 玩家语音：0dB（主音轨）
- BGM：-15 到 -20dB
- 音效：-5 到 -10dB
- 游戏原声：-10 到 -15dB（保留氛围）

---

## 第六步：片头片尾与输出

### 片头（3-5秒）
- 游戏 logo + UP 主名称 + 本期标题
- 快闪 3-5 个高光画面
- BGM 从开头就进入

### 片尾（5-8秒）
- "求点赞加关注，下期更精彩"
- 下期精彩预告（1-2 个镜头）
- 关注按钮动画/二维码
- BGM 渐弱

### 输出设置
- 格式：MP4（H.264）
- 分辨率：1080p（1920×1080 横屏 / 1080×1920 竖屏）
- 帧率：30fps（快节奏可用 60fps）
- 码率：8-12 Mbps
- 音频：320kbps AAC

### 命名
`{游戏名}_{类型}_{日期}.mp4`
例：`云顶之弈_精彩集锦_20260917.mp4`
